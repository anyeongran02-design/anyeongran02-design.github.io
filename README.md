# 봉화군지역사회보장협의체 홈페이지

`index.html` 파일 하나로 된 홈페이지입니다. GitHub Pages로 무료 호스팅됩니다.

- 주소: https://anyeongran02-design.github.io/community-council/

## 내용 고치는 법

`index.html`을 열고 `<script>` 아래 **"여기만 고치면 사이트 전체에 반영됩니다"** 부분을 수정하세요.

- `SITE`: 협의체 이름, 주소, 전화, 위원장, 통계 숫자, 읍·면 목록, 계획서 폴더 링크, 네이버 지도 키
- `NOTICES`: 공지사항 (맨 위에 새 글을 추가하면 홈 화면 소식에도 나옵니다)
- `GALLERY`: 활동 갤러리
- `PROJECTS`, `TEAMS`: 주요 사업, 실무분과 소개

GitHub 웹사이트에서 파일을 열고 연필(✏️) 아이콘으로 바로 고쳐 저장(Commit)하면 1~2분 뒤 사이트에 반영됩니다.

## 네이버 연결

- **네이버 지도**: 지금은 '네이버 지도에서 보기' 버튼으로 연결됩니다. 지도를 페이지 안에 띄우려면 네이버 클라우드 플랫폼 Maps의 Client ID를 `SITE.naverMapKey`에 넣으세요.
- **네이버 검색**: 서치어드바이저에서 받은 소유확인 코드를 `<head>`의 `naver-site-verification`에 넣고, 사이트맵(`sitemap.xml`)을 제출하세요.
