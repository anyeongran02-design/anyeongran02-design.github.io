# ○○군지역사회보장협의체 홈페이지

`index.html` 파일 하나로 된 정적 홈페이지입니다. GitHub Pages로 무료 호스팅됩니다.

## 내용 고치는 법

`index.html`을 열고 `<script>` 아래 **"여기만 고치면 사이트 전체에 반영됩니다"** 부분을 수정하세요.

- `SITE`: 지역명, 협의체 이름, 주소, 전화, 위원장, 통계 숫자, 읍·면 목록
- `NOTICES`: 공지사항 (맨 위에 새 글을 추가하면 홈 화면 소식에도 나옵니다)
- `GALLERY`: 활동 갤러리
- `PROJECTS`: 주요 특화사업

GitHub 웹사이트에서 파일을 열고 연필(✏️) 아이콘으로 바로 고쳐 저장(Commit)하면 1~2분 뒤 사이트에 반영됩니다.
